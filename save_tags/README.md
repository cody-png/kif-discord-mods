# Save Tags

Author unknown. Imported from the KIF Discord for KIF's Discord Mods catalog. This page describes version 1.0.1.

## What it does

- Gives a save a short text tag, such as "Nuzlocke" or "Challenge Run", so you can tell your saves apart.
- The load screen shows the tag after the save slot's name, for example "File A - Nuzlocke".
- The save screen shows it as a "Tag" line at the bottom of the box with your name, play time, badges and Pokédex.
- A save with no tag looks the same as without the mod.

## Installing

Options > Mods > Browse > Discord Mods > Save Tags. It starts working the next time the game starts. If Mods is greyed out, set Options > KIF Settings > Modules > Mod Settings to On first.

## How to use it

- Load the save you want to tag.
- Go to Options > KIF Settings > Mods > Save Tags settings and choose Change Save Tag. The same button is also under Settings by category > Interface.
- Type the tag at "Enter save tag:". It can be 1 to 20 characters.
- The game answers "Save tag set to:" and your tag.
- Save the game. The tag is stored in that save file, so each save keeps its own tag.
- On the load screen, each slot shows its own tag when you switch to it.
- On a Nuzlocke run that is over, the tag goes after the tombstone mark.

## Changing or removing a tag

- The entry box starts empty. What you type replaces the old tag.
- You can't leave the entry box with it empty. To keep your old tag, type it again.
- To remove the tag, enter a single space. The game says "Save tag set to: None". Save the game to make it stick.

## Settings

- Change Save Tag is the only entry. It is a button, not an on/off setting.
- Unlike most mod settings, it changes only the save you are playing, not every save.

## Changes for KIF

- The original replaced the whole load screen and save screen with copies from an older Pokémon Infinite Fusion version, and it did not load on KIF.
- This version keeps KIF's own load and save screens and only adds the tag to them.
- Saves made before you installed the mod load normally, with no tag.
- If you remove the mod, your saves still load. The tag is dropped the next time you save.

## Limits

- Set the tag while you are playing that save. A tag chosen from the title screen's Options is replaced by the save's own tag when you continue.
- The slot list you see when you choose "Save to another slot" does not show tags.
