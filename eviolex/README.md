# Eviolex

By Theanimenerd478247. Imported from the KIF Discord for KIF's Discord Mods catalog. This page describes version 1.0.1.

## What it does

- Adds the Eviolex, an attacking version of the Eviolite. The Eviolite raises Defense and Sp. Def; the Eviolex raises Attack and Sp. Atk instead.
- A Pokémon holding it gets 1.5x Attack and 1.5x Sp. Atk when it attacks, as long as it can still evolve.
- "Can still evolve" is the same check the Eviolite uses. A fused Pokémon counts if either of its halves can still evolve.
- A fully evolved Pokémon that holds it gets no boost.
- The feature description is based on the author's notes.

## Installing

- Options > Mods > Browse > Discord Mods > Eviolex.
- It starts working the next time the game starts.
- If Mods is greyed out, set Options > KIF Settings > Modules > Mod Settings to On first.

## How to use it

- Buy it in the Kuray Shop: open the pause menu and pick Kuray Shop. It costs 4,000.
- The Kuray Shop is in the pause menu only while Options > KIF Settings > Modules > Kuray Shop is On or Hidden.
- It also needs Options > KIF Settings > Game > Kuray QoL to be On (On by default).
- The Kuray Shop can't be opened during the Bug-Catching Contest or in the Elite Four and Champion rooms.
- The Eviolex goes in the Items pocket. Give it to a Pokémon to hold, like any held item.
- It has no settings.

## Changes for KIF

- The original mod had no way to get the item. KIF's copy adds it to the Kuray Shop at the Eviolite's price.
- The item's bag icon and its held-item icon now show up in KIF.

## Limits

- The Kuray Shop is the only place that sells it.
- Streamer's Dream does not make it free.
- Like other held items, it does nothing while held items are blocked, for example by Klutz, Embargo or Magic Room.
- While this mod is on, the Favorite Outfit item shows the Eviolex's name and description. It still works as the Favorite Outfit.
